## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/thohebul/WebCraft_Studio.git
```

### 2. Navigate to the Project

```bash
cd WebCraft_Studio
```

### 3. Run the Website

Open `index.html` in your browser.

For development, you can use **VS Code with Live Server**.
